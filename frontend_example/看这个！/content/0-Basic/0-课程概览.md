# 从数学直觉到 Transformer

Transformer 并不是从注意力机制突然开始的。它建立在函数、向量、矩阵和优化这些基础概念之上。

## 这张学习地图如何阅读

- 圆点表示一个可以独立学习的知识点。
- 连线表示前置依赖，建议沿着箭头逐步推进。
- 完成一个节点后，后续节点会变为可学习状态。

## 一个简单目标

我们最终希望理解下面这类计算：

\[
\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

现在不需要记住公式。先建立对输入、变换和输出的直觉。

> 每一节只需要掌握一个核心想法。遇到陌生术语时，可以先沿着图谱返回前置节点。
