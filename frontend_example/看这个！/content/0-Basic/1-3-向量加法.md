# 向量加法

两个维度相同的向量可以逐项相加。

\[
\begin{bmatrix} 1 \\ 2 \end{bmatrix} +
\begin{bmatrix} 3 \\ 4 \end{bmatrix} =
\begin{bmatrix} 4 \\ 6 \end{bmatrix}
\]

## 几何直觉

把第二个向量的起点放到第一个向量的终点，两个向量连成的终点就是相加结果。

在 Transformer 中，词向量会与位置编码相加，让模型同时知道“是什么”和“出现在哪里”。

```python
token = [0.2, 0.4]
position = [0.1, -0.2]
result = [a + b for a, b in zip(token, position)]
```
