## 3. 工程与验收遗留

- **B5 错误配方正式撤销**：不得把 `records.py` 机械改成同步 `def` 并删除 `await`。当前 Mongo 使用 Motor，查询、插入、补偿删除必须 await；同步 SQL 的确会占用事件循环。后续应保留异步 Mongo，采用 Session 生命周期完整的 SQL 线程池工作单元，或系统迁移异步 MySQL/AsyncSession；与 D3 一起审查事务边界。
- **类型化（原 B6）**：Simulator、Detail、Dashboard、Layout 的脚本仍未使用 `lang="ts"`。旧文档的 68 个错误是历史临时实验数字，不是本次计数；普通构建通过不代表全部 JS 业务已有严格类型保障。
- **Element Plus 按需加载（原 B7）**：`main.ts` 仍全量导入和注册。实施需同时覆盖组件、字符串图标、v-loading、服务样式及生产验收。“省 368 kB”是旧对照实验，不是按需方案的承诺收益，也不是每次路由切换都会重新下载。
- **关键测试缺口**：标签/日历 CRUD、跨库存储失败、Mongo 缺失或损坏、行情异常、SSE 中断和缺 key，以及 D1–D8 相关边界。补行为覆盖不以安装 pytest/eslint 为前提。
- **请求生命周期**：TradeSim 的超时、取消、页面离开或关闭 AI 时的中断处理未闭环。
- **交互半实现**：图表点击流水目前只有提示和 console.log，尚无实际滚动/高亮；反向表格到图表已有实现。
- **视觉验收**：窄屏、动态偏好切换、主题提示、图表/流水、路由刷新及浏览器错误检查，见 `docs/1` 的验收边界。减少动态效果的若干实现已存在，不应再记为“完全未做”。

## 4. 候选产品与可选工程决策

以下不自动纳入本轮实施范围，是否执行及顺序只在根 `todolist.txt` 维护：

- 开放式基金长期低频回测：净值/分红数据、申赎费用、确认到账、持有期、信号延迟与比较基准尚未建模；当前股票百股模型不能直接替代它。
- 年化收益：引擎仍固定返回 0.0，需先计算再增加读接口与展示；年线策略仍是占位页。
- 日历编辑与标签管理：后端具备部分写接口，前端尚无完整功能。

- 主题切换与偏好保存、首页静态统计接真实数据、储物间动画均属新需求；当前保留/占位行为不是清理缺陷（P6）。
- 早期设计对照新增候选：Notes持久化（P9）、真正的公式排版（P10）、Markdown导入Frontmatter与正文分离（P11）；证据见docs/10。旧物理布局和侧抽屉方案已替代，不要求恢复。

- 对外服务和生产部署才需要鉴权、SPA fallback 等部署工作；继续保留本机绑定。
