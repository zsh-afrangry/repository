### 1.1 高：必须修，否则是真实缺陷或明确割裂

| ID | 问题 | 一句话证据 |

| **H1** | TradeSim 的全局浅色 markdown 样式泄漏到门户笔记阅读器，**笔记文章区会变白底** | `TradeSimSimulator.vue:8`、`TradeSimDetail.vue:8` 在 script 里 `import 'github-markdown-css/github-markdown-light.css'`（全局生效）；该包 `.markdown-body{color:#1f2328;background-color:#ffffff;font-family:-apple-system…;font-size:16px}`；门户 live 侧 `Notes.vue:1521` 用 `class="reader-document markdown-body"`，而 `Notes.vue:2236-2240` 的 `.reader-document` **只设 width/margin、无底色无字色** → 全局规则胜出。CSS 分包注入后不卸载，故为「先访问 TradeSim 再回笔记页」才复现的偶发 bug。**这条同时也是对 `AGENTS.md` 明令边界的直接违反**——原文写「Preserve this boundary — an unscoped style block or a global Element Plus theme override will leak into the portal」，而 H1 正是一个 script 侧的全局 CSS import |

## 5. 后端：架构与接口契约（子代理专审 + 主会话复核）

### 5.1 分层与边界

- **TradeSim 边界确认干净**：全量 grep 确认其对外引用**只有** `app.models.bill.Base` 与 `app.database.get_db` 两条，无反向依赖。（原约定的这个边界成立。）

### 5.3 接口契约要点
