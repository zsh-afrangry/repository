# 1_ 前端界面背景与特效整理

本文是现行效果登记册：保留命名、启用边界、实现状态与验收范围，覆盖更新，不追加历史日志。执行与完成勾选统一在根 `todolist.txt`。审计证据见 `docs/9_文档核查与交接遗留清单.md`；2026-10-04 首页/账单修复及浏览器验收见 docs/12_首页与账单收尾验收.md；随后启动 Notes 视觉第一批试做，范围与验证见 docs/13 §7。

## 1. 效果命名与计数口径

| 名称 | 含义 | 计数边界 |
|---|---|---|
| BG_BASE_DARK | 页面/路由基础底色 | 纯色或一个渐变为基础层 |
| BG_GLOW_GLOBAL | 覆盖路由的静态径向光晕 | 每个独立渐变计一个子层 |
| BG_GLOW_SECTION | Hero 或区块局部光晕 | 与全局光晕分开登记 |
| BG_PARTICLE_AUTO | 自动漂移、连线的 Canvas | 一套 Canvas 计一个动态层，不按粒子数计 |
| SURFACE_GLASS | 内容卡片填充、边框、模糊 | 属内容表面，不计全局背景 |
| SURFACE_GLOW_LOCAL | 卡片/控件内部装饰光晕 | 属局部表面 |
| FX_CURSOR_SPOTLIGHT | 光晕中心跟随鼠标 | 与普通 hover 区分 |
| FX_CURSOR_PARTICLE | 鼠标参与粒子吸引或连线 | 与自动粒子运动区分 |
| FX_HOVER_SURFACE | 卡片边框、阴影、透明度或位移反馈 | 不另算鼠标跟随光晕 |
| FX_HOVER_CONTROL | 控件 hover/focus/active 反馈 | 按用途登记 |
| FX_FOCUS_STATE | 键盘/辅助技术焦点反馈 | 不依赖鼠标 |

`mask-image`、opacity、transform、backdrop-filter 是合成/材质属性，不单独算背景层，但应关注性能。实例数与效果种类分开；统计动画时区分动画名称、作用域内定义、媒体查询重定义。旧文档的 RAF/transition/定义总数不作为当前恒定值。

| Notes | 专题图谱/全屏阅读器、搜索颜色高亮、页面自己的动态偏好处理；旧脉冲样式存在不等于当前节点使用 | 不把 Markdown 正文示例当真实导入或执行代码 |
| TradeSim | 共享静态背景、浅色 Element Plus 内容表面、收藏页淡入、控件反馈 | 不启用 Hero 粒子或鼠标光晕；不在整理时顺带全量改暗色主题 |

当前命名动画：Dashboard 的 `cal-dot-pulse`、Dashboard/TradeSimDashboard 各自的 `fadeIn`、Notes 的 `pulse`、全局 `waterfall-fade`。两个 fadeIn 属不同 scoped 样式，时长/缓动不同，不是同一共享动画；若合并需保留各自参数。媒体查询内的覆盖也要计入实现审查。

主题按钮仍只显示“功能待开发”，约 3 秒后消失；`.theme-light` 及 `updateThemeClass()` 的亮色分支刻意保留。提示条在视口中间偏上，桌面 top 10%、窄屏 top 8%（2026-10-06 由 20%/14% 上移，用户要求；样式未改）；进出过渡应保留水平 -50% 居中。是否顺眼属于视觉验收，不由位置参数证明。

## 3. 减少动态效果与生命周期

**以下已在源码实现，不再列为“尚无降级”；实现存在不等于全站动画已验收。**

| 位置 | 当前减少动态效果行为 | 仍需验证 |
|---|---|---|
| `App.vue` | 读取/监听 prefers-reduced-motion；开启时不创建或销毁 Lenis，关闭时可重建；卸载移除监听并停止 RAF | 初始开启、运行时来回切换、滚轮/原生滚动体验 |
| `StarfieldBackground.vue` | 开启时停止循环、保留/绘制静态帧；resize 后补画；卸载清理监听和 RAF | 初始开启、切换、窗口尺寸变化是否有空白或额外循环 |
| `Dashboard.vue` | Hero 粒子监听动态偏好，减少动态时停止 RAF，恢复时重启；有 CSS 降级 | 首次进入、切换与缩放后的画面；各控件/锚点滚动是否符合预期 |
| `Notes.vue` | 新工作区使用静态背景/网格，按钮有 CSS 降级，App 管理 Lenis | 本轮动态偏好切换、浮层焦点/滚动及窄屏已验收；旧抽屉和脉冲方案已被替代（docs/13） |
| `TradeSimDashboard.vue` | CSS 重定义 fadeIn，取消 translateY，只保留透明度变化 | 收藏页入场与路由往返 |
| `styles/main.css` | 减少动态时 waterfall-fade 取消位移/缩放，保留淡入 | 账单列表的延迟入场与可读性 |

这张表不代表 ECharts、所有 hover、程序化平滑滚动或所有过渡均已覆盖。原先将 TradeSimDashboard 的降级描述为 ECharts 降级不准确，当前明确实现的是页面 CSS 淡入。

`useScrollReveal()` 在调用瞬间扫描 `.reveal-item`，需在 DOM 挂载后调用；调用方持有 observer 并在卸载时 disconnect。当前 Dashboard 已做卸载清理；2026-10-04 将筛选改为保留原节点，原观察关系不再因筛选丢失。重复搜索/状态切换与恢复后的逐卡可见性已通过浏览器检查。后续如改为动态增删项目，仍需显式观察新节点。


## 4. 后续修改约定

1. 完整静态背景优先复用 KnowledgeMapBackground；需要独立拆卸光晕/网格时使用 ui/AmbientGlow、ui/GridDecoration，避免重复底色。背景组件不能替消费者决定布局和整套配色。
2. 一个路由不同时挂 Dashboard Hero 粒子和 StarfieldBackground；新增持续效果要说明用途、降级与清理方式。
3. 视觉背景使用 `pointer-events: none`，交互监听放内容容器，不用透明覆盖层截获控件事件。
4. RAF、observer、事件监听、定时器均需明确创建/停止/卸载责任；构建通过不能证明无生命周期泄漏。
5. TradeSim 保持 scoped 样式与 `.tradesim-markdown` 命名空间。`.tradesim-layout` 的 `isolation: isolate` 负责层叠上下文，**并不能隔离 CSS 选择器**，不能替代 scoped/命名空间。
6. 保留浅色主题变量、用户明确保留的导出和归档页自有样式；不依据单次“无引用”搜索直接删除。
7. 保留功能性 hover/focus 状态，先保证内容对比度；新增光晕、模糊和动画前考虑窄屏、减少动态及性能。
8. 修改效果时原地更新本登记册的范围与验证状态；不追加逐轮纠错日志，不复制根待办。
