## 本目录各文件职责

- **1：效果登记册。** 维护当前启用范围、命名、清理和降级约定；不再堆叠长时间线。
- **6：当前状态。** 覆盖更新，摘要说明完成/未完成/待确认，不复制整份待办。
- **8：接手指南。** 保留运行与排障入口、数据边界；测试通过不能被概括成“没有代码问题”。
- **9：核查报告。** 保留核查基线、证据与验证边界；本轮整理不代表其中缺陷已修。
- **10：早期设计整理。** 将20260625的原始方案与现行代码对照，区分已实现、已替代和候选需求。
- **历史设计原稿/20260625/**：保留原四份设计文件和层级，供追溯；根目录旧文件夹已移除。

编号2、3、4、5、7刻意保留空位，因为对应原件已移入 `已归档/`；不重新编号，避免旧引用混淆。归档文件和整理前快照的定位见归档导航。

## 更新规则

1. 实施任务后在根 `todolist.txt` 更新稳定ID、状态和相关验证；本轮仅整理文档，D/E/V/P项未因此完成。
2. 修改背景/动画时同步文件1；状态变化同步文件6；启动、环境或保留边界变化同步文件8和AGENTS。
3. 文件9的核查结果有版本和验证范围，后续修复应记录新结果，不把历史实测冒充实时状态。
4. 归档文件4保持冻结；其余归档材料及整理前快照保留历史原文，旧路径由映射表解释。
5. 改文档结构时同步入口与引用。新增长记录另作阶段报告，不再塞进当前状态或待办。
6. 不以文档“已完成”替代源码与相应验证，也不把有意保留的主题、静态占位、旧数据兼容当作清理任务。
