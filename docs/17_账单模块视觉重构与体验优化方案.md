# 17 · 账单模块视觉重构与体验优化方案

日期：2026-10-08 起。作用域：**账单模块（`/bills`）**。
前序收尾基线：[docs/12_首页与账单收尾验收.md](12_首页与账单收尾验收.md)；执行状态以根 [todolist.txt](../todolist.txt) 为唯一清单。

---

## 1. 目标与背景

账单模块（`frontend/src/views/Bills.vue`）承担个人的日常记账、月度收支总览、分类汇总及流水管理。在此前的缺陷收尾中（见 `docs/12`），已完成了编辑丢小类修复、日分组折叠、月记录截断消除、切月竞态防范及基础键盘弹窗保护。

然而，现有页面仍保留早期原型阶段的局部设计特征，存在以下明显的视觉与体验重构诉求：
1. **顶栏断裂与全局不一致**：目前使用私有的粘性 Header（`Dashboard` 纯文本面包屑与朴素按钮），未接入全站统一的 `AppNavbar` 统一顶栏；
2. **版心局促、展示受限**：目前整体容器限制在 `max-w-2xl`（约 672px），在大屏桌面端两侧大面积留白，月度概览与流水信息被紧逼在狭长通道内；
3. **月度看板维度单一**：月度收支卡片仅有简单的“收入/结余/支出”三栏与一条支出占比条，缺乏分类支出构成、趋势与核心指标的结构化呈现；
4. **流水列表信息层级混杂**：日卡片与流水行缺乏现代微光质感与呼吸感，金额与标签排布紧贴，缺少高效的分类筛选与检索工具；
5. **记账录入交互可提效**：新建/编辑弹窗表单为全量表单字段堆叠，缺少金额大字号沉浸输入、常用分类快选、报销状态醒目标记等高效记账手感。

本方案旨在建立账单模块现代、精致、高效的视觉系统与交互体验，保持后端现有接口与数据契约 100% 兼容。

## 3. 重构方向与核心设计规划

### 3.1 视觉套件复用与组件化（需求 1：DeepSpaceBackground）
* **背景与特效统一提取**：新建 `frontend/src/components/DeepSpaceBackground.vue`，作为全站即插即用的模块化背景插件：
  * **底色层**：整合 `KnowledgeMapBackground` 的深邃冷黑底色与微弱径向渐变（`#0f0f14`）；
  * **粒子层**：整合 `StarfieldBackground` 的 2D Canvas 动态星轨，自带光标引力聚拢（Mouse Attraction）与光标动态星座连线，并在组件卸载时安全回收 `cancelAnimationFrame`；
  * **微光层**：整合 `AmbientGlow` 的紫蓝双色弥散冷光，打破死板黑底；
  * **网格层**：整合 `GridDecoration` 的精密未来感坐标暗网格；
  * **性能与无障碍**：通过 props（`enableParticles` / `enableGlow` / `enableGrid`）灵活控制，自动侦测 `@media (prefers-reduced-motion)` 自动降级为静态背景。

### 3.2 日历优先架构大重构（需求 2：Calendar-First Architecture）
改变传统“单一流水流堆叠”模式，重塑为以**整月日历看板（Calendar-First）为主体、日明细并排检视、全月流水按需抽屉化**的高效个人财务工作台：
1. **整月日历看板（主栏 8 列，`lg:col-span-8`）**：
   * 周一至周日标准 7 列表头；
   * 精确计算当月真实天数及跨月灰色填充格；
   * **单元格语义化呈现**：
     * 日期数字：非当月弱化、当月清晰、今天散发极光青冷光徽章（`is-today`）；
     * 收支汇总：当日支出以玫红等宽字标示（如 `-12.50`），收入以翡翠绿等宽字标示；
     * 分类特征徽章：识别当日核心消费大类并显示专属 Emoji 徽章（如 🍴 餐饮、🚗 交通、🛍️ 购物、🏠 居住、🎮 娱乐等）；
     * 笔数与状态：右上方显示 `N笔` 计数胶囊，有待报销项目时闪烁琥珀黄感叹号标记；
     * 悬浮快捷记账：鼠标悬停在日期单元格右下角浮现 `+` 快捷按钮，点击直接带入该日期进入记账弹窗。
2. **选中日与日明细检视器（Day Detail Inspector，副栏 4 列，`lg:col-span-4`）**：
   * 采用桌面端**左右并排非遮挡布局**，彻底避免浮动 Drawer 在大屏遮挡日历第 7 列（周日）单元格的交互缺陷；
   * 点击日历任一日单元格，该单元格高亮紫青霓虹光圈，右侧面板即刻聚焦该日：
     * 头部显示选中日期、星期、该日账单笔数与该日净收支；
     * 逐笔卡片呈现：分类 Emoji 头像、二级分类、记录时间、金额大字号、备注、支付平台/渠道低噪胶囊、报销状态标签、快捷编辑与删除按钮；
     * 底部常驻 `+ 在该日新增记录` 快捷按钮；
   * 未选中日期或该日无记录时，右侧自动无缝切换为**当月财务宏观概览**（支出 Top 5 分类排行榜与报销进度追踪看板）。
3. **全月流水独立抽屉（Full Stream Drawer）**：
   * 顶部常驻快捷切换入口：`📜 全月流水清单 (N 笔)`；
   * 点击从右侧滑出全屏沉浸抽屉，内置实时关键词搜索栏（支持搜索分类、备注与金额）、类型切换 Tab（全部 / 仅支出 / 仅收入 / 待报销），以及按日分组的传统完整瀑布流卡片。
4. **月度 KPI 财务指标看板升级**：
   * 顶部固定保留 `[data-testid="monthly-summary"]` 契约节点；
   * 清晰呈现总收入（翡翠绿）、总支出（玫红）、净结余（冷紫）；
   * 智能统计指标：日均支出计算、有效记账天数、当月总流水笔数、收支占比微光进度条。
5. **记账录入与编辑弹窗（Modal）**：
   * 沉浸式金额大字号输入（`¥` 符号 + 极佳光标对齐）；
   * 收支双段 Segment 快速切换；
   * 常用高频分类快捷 Chip（一键填入大类）；
   * 一级大类选择自动联动二级子类；
   * 完整支持 Enter 保存、Esc 退出以及 Tab 焦点闭环。
